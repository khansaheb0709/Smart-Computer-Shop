☁️ Google Drive ব্যাকআপ

ব্যাকআপ JSON সরাসরি আপনার Google ড্রাইভের (অ্যাপের লুকানো ফোল্ডারে) আপলোড হয় — শুধু এই অ্যাপই দেখতে পায়। রিস্টোর করলে ফাইলটি ডাউনলোড হবে; আসল রিস্টোর tools/restore-backup.sql দিয়ে (docs/07_Runbook)।

প্রথমবার সেটআপ (একবারের কাজ):
১. console.cloud.google.com → প্রজেক্ট তৈরি/বাছুন → APIs & Services → Library → Google Drive API চালু করুন
২. OAuth consent screen → External → অ্যাপের নাম “সেবাঘর ব্যাকআপ” → Save
৩. Credentials → Create Credentials → OAuth client ID → Web application
৪. Authorized JavaScript origins: এই সাইটের ঠিকানা (যেমন https://<your-domain> ও GitHub Pages URL)
৫. নিচের বক্সে Client ID পেস্ট করে সেভ করুন — অথবা assets/js/config.js-এ GOOGLE_DRIVE_CLIENT_ID-এ বসিয়ে দিন

ড্রাইভের ব্যাকআপসমূহ

“ড্রাইভে সংযুক্ত করুন” চাপুন।

টোকেন: দিনের প্রথম অর্ডারে ১ থেকে শুরু — প্রতিদিনের সর্বোচ্চ নম্বরের সাথে ১ যোগ করে বসে, কোনো ক্রমিক নম্বর (sequence) নেই, তাই টোকেন কখনোই “desync” হয় না। দোকানের ডেটা ওয়াইপ করলেও টোকেন নিজে থেকে ঠিক হয়ে যাবে। কেউ হাতে অর্ডার হারিয়ে দিলে সর্বোচ্চ টোকেন যাচাই: select order_date, max(token) from orders group by 1 order by 1 desc;
